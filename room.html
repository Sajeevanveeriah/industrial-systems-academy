Room overview
Commissioning brief and design assumptions

Work order SW-042: commission a single historian on the plant services network. Use the service bay; preserve the doorway and the cooler service zone. Point the rack intake towards the cold aisle. In this training design the UPS occupies U1 and U2. The other devices may use any non-overlapping free spaces.

The PDU already feeds the server and switch; the UPS input has a utility feed. Patch P01 is already terminated to the upstream distribution switch. You need to connect the three remaining leads. The primary server interface is reserved as 10.42.8.20/24; use gateway 10.42.8.1, DNS 10.42.8.10 and access VLAN 42.

The utility fault removes only the rack’s utility feed. The upstream distribution switch has independent power. The model observes a charged UPS at one instant; it does not simulate elapsed time, battery depletion or endurance. A pass verifies only this fictional configuration, not a physical room, electrical installation or UPS runtime.
